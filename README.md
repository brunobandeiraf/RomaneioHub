# RomaneioHub

Sistema de gestão de pedidos com fornecedores e notas fiscais.

## Estrutura

- `frontend/` — Next.js (deploy na Vercel)
- `backend/` — NestJS + Prisma (deploy no Railway)

## Desenvolvimento

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm run dev
```
